# Berkontribusi

1. Buat cabang dari `main` dengan awalan: `fitur/`, `perbaikan/`, `dokumen/`, `rapikan/`, `tes/`, `rawat/`.
2. Gunakan Conventional Commits, contoh: `fitur: formulir kirim karya langkah 2`.
3. Buka PR, lalu minta satu reviewer. Merge dengan squash.
4. Jangan commit `.env` atau rahasia apa pun.
